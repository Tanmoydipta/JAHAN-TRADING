TROUBLESHOOTING QUICK REFERENCE:

Issue: "No module named flask"
→ Exe was built with Python 3.12 which has no Flask installed.
→ Solution: Rebuild exe using Python 3.14+
  $ C:\Python314\python.exe build.py

Issue: Database connection fails
→ Customer's MySQL is unreachable.
→ Ask them to:
   1. Check cloud provider dashboard (DB is running?)
   2. Verify hostname/username/password (exact match?)
   3. Check firewall rules in cloud provider (your IP allowed?)
   4. Re-test connection string manually if possible

Issue: App is slow
→ Normal over internet. Aiven free tier is especially slow.
→ Recommend upgrading to DigitalOcean or local MySQL.

Issue: Duplicate Chalan numbers / data corruption
→ This is not a known issue. Ask for detailed steps to reproduce.
→ Check database logs in cloud provider's dashboard.
